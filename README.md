# 节奏人杯 算分器

本比赛采用明日方舟集成战略《沉沦者的黑流树海》n15 难度，赛程分为海选赛与决赛两个阶段，赛制为四人团队赛。本仓库提供比赛用的单页算分器（`index.html`）：页面按 3 名普通位与 1 名抗压位分别保存四名队员的填写数据，录入结算界面数据与各加扣分项后即时计算每名队员的个人最终得分与团队总分，并可复制全队计分明细。

## 使用

在线访问（GitHub Pages）：<https://programme404.github.io/RhythmCup/>

纯静态页面，无需安装依赖，直接用浏览器打开 `index.html` 即可。页面背景图取自 prts.wiki，离线打开时会退化为默认底色，不影响计分。

页面最上方的“参赛位置”用于切换队员：点击普通位①②③或抗压位即可切换，各队员已填写的数据会保留在后台，切换不会丢失。右侧统计区显示四名队员的个人得分与团队总分，下方明细对应当前选中的队员；“清空当前”只清空当前队员，“清空全队”清空四名队员与全队项。

## 计分规则

个人最终得分 = 个人分 × 位置系数（普通位 ×1.0，抗压位 ×1.3）

### 结算基础分

| 项目 | 分值 |
| --- | ---: |
| 结算分 | ×0.8 |
| 结算页面藏品 | 每个 +5 |
| 零件 | 每个 +2 |
| 褴褛猫、褴褛狗 | 每个 +10 |
| 其余褴褛 | 每个 +20 |

| 项目 | 分值 |

### 全队项（计入团队总分，不计入个人最终得分）

| 项目 | 分值 |
| --- | ---: |
| 全队无人通关一结局 | -200 |
| 全队无人通关二结局 | -300 |
| 全队无人通关三结局 | -500 |
| 全队源石锭提取超过 300 | 每超出 1 元 -50 |

### 本局分数无效

普通位结算时未携带沙盘；抗压位未携带双沙盘、未携带三个削弱藏或未完成全追猎（含 3/5 层 Boss），按规则五本局分数无效，算分器将个人最终得分记为 0 并在明细中给出提示。页面中的“位置要求”一栏即为该项校验。

## 赛制要点

- 采用 n15 规则，海选赛与决赛两阶段。
- 团队赛，队伍数量不限；每队 4 名选手，4 人必须选用不同分队开局，重复使用同一分队开局时仅第一次使用该分队的队员计分。
- 每队 3 名普通位与 1 名抗压位：普通位结算时至少携带一个沙盘；抗压位强制进行全追猎，并在结算时携带双沙盘与三个削弱藏，其最终得分在个人分基础上 ×1.3；未满足位置要求则本局分数无效。最终分数前三名进入决赛。
- 全队 4 名选手必须全部为舰长群一群群友。
- 开局禁止携带褴褛，可无限烧水开局；局内获得的褴褛按上表加分。
- 通过二层前无条件允许重开一次，此后出现任何情况导致结束探索均视为直接失败。
- 每队限制三次连麦，每次连麦时长不超过三分钟；禁止主动利用 bug。
- 奖金：冠军 600 元，亚军 400 元，季军 200 元；其余参赛战队平分 400 元，平分金额上限 100 元，剩余队伍少于 4 队时剩余奖金由前三队平分。参与奖金评分需队内至少通关三结局一次。
